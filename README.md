# exportar_todas_as_camadas_Dos_projetos_photoshop
Este script para Photoshop exporta todas as camadas visíveis (exceto a última) de documentos abertos como PNGs. Ele solicita uma pasta de destino, duplica cada documento, oculta outras camadas, aplica um recorte e salva as camadas visíveis. O documento duplicado é fechado sem salvar, e uma mensagem de conclusão é exibida.
